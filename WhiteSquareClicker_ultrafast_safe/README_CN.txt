WhiteSquareClicker UltraFast Safe

This version will not start until you set the scan area.

Keys:
F6 = set first corner of scan area at current mouse position
F7 = set second corner of scan area at current mouse position
F8 = start / pause
F9 = emergency pause
ESC = exit

Recommended use:
1. Run the exe.
2. Move mouse to the top-left corner of the possible white-square area, press F6.
3. Move mouse to the bottom-right corner of the possible white-square area, press F7.
4. Press F8 to start.

If the cursor jumps to a wrong place, press F9 or ESC immediately.
